# Game rental project

This repository was created for a game-rental program (`Programa para aluguel de jogos`). No application source or runnable release has been committed.

## Status

There are no installation instructions, tests or demo to run yet. This repository should be treated as an unfinished project, not a completed portfolio example.

A first usable version would need an inventory of games and available copies, rental and return records, persistence across restarts, and tests for unavailable stock and duplicate returns. Those features are not implemented here.

For current work, see [Almeida96's repositories](https://github.com/Almeida96?tab=repositories).
